# Guardrails PoC — context for a new session

Paste this into a fresh session to pick up where we left off.

## What this is
A **client-facing, runs-anywhere** proof-of-concept notebook:
[`notebooks/guardrails_poc.ipynb`](guardrails_poc.ipynb). It shows how the **real SafetyNet
library** wraps the kinds of agents the client is building (image/video, movie-script,
LangGraph/NeMo/CrewAI), and demonstrates that guardrails **measurably reduce unsafe content**.

- **No GPU, no API keys.** Imports SafetyNet from the repo `src/` if present, else `pip install`s
  it from GitHub. Builds its policy **inline** (`load_policy_from_dict`) so there are no file
  dependencies. Only third-party needs: PyYAML (a SafetyNet dep) + Pillow (image/video agents).
- The notebook is generated by a re-runnable builder: **`notebooks/_build_poc_notebook.py`**
  (same pattern as `examples/_build_colab_notebook.py`). Edit the builder, then
  `python notebooks/_build_poc_notebook.py` to regenerate the `.ipynb`.

## Structure (8 sections, 13 runnable cells)
0. Title + what SafetyNet is + ask→section map.
1. Setup: ensure import, **inline policy**, character bible, pretty-printers.
2. **Meet the agents** — offline `ScriptAgent` / `ImageAgent` / `VideoAgent` (image agents render
   real PIL pixels so the vision gate has something to inspect). Note on where LangGraph/NeMo/
   CrewAI/Dify clients plug in.
3. **Multi-agent movie-production workflow** — a Director chains Script→Image→Video, each wrapped
   by `GuardedAgent`; pipeline halts if any node blocks.
4. **Mitigation techniques (4):** (a) block-before-spend at PRE; (b) **PII/secret redaction** then
   proceed; (c) **output/image moderation + safe fallback** at POST (uses `DemoVisionBackend`, a
   color-heuristic stand-in for Azure/AWS/CLIP); (d) **evasion-resistant matching** (homoglyph/
   zero-width/leet/Base64 all caught).
5. **Proof it reduces unsafe content** — a 10-brief mixed batch, unguarded vs SafetyNet-guarded.
   Result on the sample batch: **6/10 → 0/10 unsafe outputs auto-delivered (100% reduction)**, with
   FLAGged borderline items held for human review (`human_review_on_flag: True`), not auto-published.
6. **Configurable ethics — Deontology arresting Consequentialism** (the differentiator). Shows the
   deontic veto, then flips the stance (`deontology_veto` / `weighted` / `strictest`) by config only.
7. **Audit trail** — JSONL record stamped with `policy_hash`.
8. **Go-to-production** — swap stub clients for `nemo/langgraph/dify/crewai` presets; flip scanner
   backends to real models (promptguard/transformers/anthropic/azure) with one config value.

## How to run
- **Repo (recommended for the team):** open in Jupyter/VS Code from the repo root; the setup cell
  finds `src/` automatically. Validated end-to-end (all 13 code cells run clean) on Python 3.11.
- **Colab:** upload the `.ipynb`; the setup cell `pip install`s SafetyNet from GitHub. Run all.

## Validation
Every code cell is exec-tested in order via the build/validate loop. `DemoVisionBackend` and the
toy renderer are clearly labelled **illustrative** (production swaps in real vision/guard models).
