# Guardrails PoC — context for a new session

Paste this into a fresh session to pick up where we left off.

## What this is
A hand-crafted, narrative PoC notebook: [`notebooks/guardrails_poc.ipynb`](guardrails_poc.ipynb).
Two real agents, guarded by SafetyNet:

- a **writer** agent built on **NVIDIA NeMo Guardrails** (`nemoguardrails`) wrapping
  `Qwen/Qwen2.5-0.5B-Instruct`, and
- an **artist** agent built on `stabilityai/sd-turbo`.

A **SafetyNet gateway** sits in front of both (defence in depth) — scanners + the Falconsai NSFW
image classifier on the artist's output.

### Key constraints honored
- **No GitHub repo URL.** SafetyNet is **vendored** into the notebook via `%%writefile` setup cells
  (30 collapsed `cellView: form` cells, same approach as `examples/_build_colab_notebook.py`), so the
  notebook is fully self-contained (only needs PyYAML, which Colab ships).
- **NVIDIA NeMo Guardrails** is the writer's framework; install cell is
  `diffusers transformers accelerate torch` + `nemoguardrails langchain-community` (no krishddd URL).
- **Ethics demo dropped** (pure-scanner framing). The ethics frameworks are still vendored (guard.py
  imports them) but **disabled in the policy**, so the gate runs on scanners only.
- Generated by a re-runnable builder: **`notebooks/_build_poc_notebook.py`**. Edit it, then run
  `python notebooks/_build_poc_notebook.py` to regenerate the `.ipynb`.

## Flow (66 cells; 30 are collapsed vendor cells)
1. Intro → installs (NeMo + models, no repo URL).
2. Imports + device pick.
3. **Setup** — vendor SafetyNet to disk (`%%writefile` cells; "skip reading these").
4. Load SD-Turbo (artist) + gut-check; load Qwen LLM + gut-check.
5. Build the **NeMo Guardrails** writer (`RailsConfig`/`LLMRails` over the Qwen pipeline, simple
   Colang refusal flow). Robust `try/except` → falls back to direct LLM if NeMo init fails, so the
   notebook always runs.
6. Inline SafetyNet **policy** (ethics disabled; scanners: prompt_injection, content_safety,
   copyright, pii; + image_moderation `backend='nsfw'` on the artist).
7. Adapter agents + `build_guard()`; display helpers.
8. Demos: happy path (script + image) · writer **jailbreak** → PRE BLOCK (injection; NeMo rail is the
   complementary layer) · artist **protected-IP** → PRE BLOCK (copyright; SD-Turbo never runs) ·
   output NSFW moderation on the generated image · PII **redaction** (block → scrub → pass) ·
   evasion folding (homoglyph/zero-width/leet/base64). **No ethics section.**
9. Wrap-up.

## Validation (done in the dev env, no torch/nemo here)
- All 18 logic cells compile; the 30 `%%writefile` cells reconstruct a working `safetynet` package
  importable with **only PyYAML** (verified by extracting them to a temp dir and running a guard —
  benign allowed, jailbreak blocked). This is exactly the Colab path.
- Guard flow exercised with stubbed models/NeMo/NSFW: happy-path ALLOW (+image), writer jailbreak →
  PRE BLOCK, artist IP → PRE BLOCK, PII block→redact→pass, all six evasion disguises BLOCK.
- The **NeMo init cell** can't be verified here (nemoguardrails not installed); it's wrapped in
  try/except with a direct-LLM fallback, so a NeMo version/config hiccup degrades gracefully.
