# Guardrails PoC — context for a new session

Paste this into a fresh session to pick up where we left off.

## What this is
A hand-crafted, narrative PoC notebook: [`notebooks/guardrails_poc.ipynb`](guardrails_poc.ipynb).
It loads **real generative models** and puts **SafetyNet** guardrails in front of two agents:

- a **writer** agent — `Qwen/Qwen2.5-0.5B-Instruct` drafts a movie-script beat, and
- an **artist** agent — `stabilityai/sd-turbo` generates concept art.

Output images are moderated by the **Falconsai NSFW classifier** (`backend='nsfw'`), the same model
the original notebook used. **No video agent** (dropped per request). Best run on a Colab/Jupyter
**GPU**; CPU works but is slow on first generations.

- Written in a natural, build-it-up voice (first-person notes, small cells, gut-checks) rather than
  a rigid spec — intentionally "how a person grows a notebook."
- Generated by a re-runnable builder: **`notebooks/_build_poc_notebook.py`** (same pattern as
  `examples/_build_colab_notebook.py`). Edit the builder, then run it to regenerate the `.ipynb`.
- Policy is built **inline** via `load_policy_from_dict` (no extra files to download).

## Flow (38 cells)
1. Intro (what/why) → installs (`diffusers transformers accelerate torch` + safetynet from GitHub).
2. Imports + device pick; safetynet import shim (repo `src/` or pip).
3. Load **SD-Turbo** (+ `generate_image`) with a quick draw gut-check.
4. Load **Qwen2.5-0.5B-Instruct** (+ `write_script`) with a quick gut-check.
5. Inline **policy** (deontology duties + consequentialism; scanners; `human_review_on_flag`).
6. Adapter agents `WriterAgent` / `ArtAgent` (artist returns `image_bytes` in metadata for the
   output gate). `build_guard()` adds `ImageModerationScanner(backend='nsfw')` for the artist.
7. Demos: happy path (script + displayed image) · harmful writer prompt → PRE BLOCK (LLM never
   runs) · protected-IP artist prompt → PRE BLOCK (SD-Turbo never runs) · output NSFW moderation on
   the generated image · PII **redaction** (block → scrub → pass) · **ethics** (deontology arrests
   consequentialism; stance flip by config) · evasion folding (homoglyph/zero-width/leet/base64).
8. Wrap-up + go-to-production (swap to nemo/langgraph/dify/crewai clients; scanner backends by config).

## Validation
Can't run the real-model cells in this dev env (no torch/transformers/diffusers). Validated by:
(a) every code cell compiles; (b) a stubbed harness that swaps `write_script`/`generate_image` and
registers a stub `nsfw` vision backend, then exercises the full guard flow — confirms happy-path
ALLOW (+image), writer harmful → PRE BLOCK, artist IP → PRE BLOCK, PII block→redact→pass, ethics
veto, and all six evasion disguises BLOCK. On Colab with a GPU the real models replace the stubs.
